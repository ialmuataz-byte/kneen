لوحة التحكّم

عدّل ألوان الموقع. التغيير فوريّ ومحفوظ في متصفّحك.

حمّل ملف index.html محدّثًا بكلّ تعديلاتك. ارفعه إلى GitHub لتظهر التغييرات للجميع.

خطوات النشر:
1. اضغط "تنزيل index.html".
2. اذهب إلى مستودعك على GitHub.
3. احذف ملف index.html القديم.
4. ارفع الملف الجديد.
5. انتظر دقيقة، حدّث الموقع.
